# 包装印前与交付核验

这是人工与AI协作的检查方法技能，不是一键送印工具。它帮助整理确认稿、刀模与文件版本，记录实际检测和未检项目。

## 使用
把整个目录作为技能交给支持 SKILL.md 的环境读取，或直接指定 SKILL.md。安装位置和发现方式以使用环境的当前文档为准；准备目录不等于已经安装或自动发现。
提供本单交付格式、已确认文件、生产规格及允许操作范围。缺失信息会列为待确认。
示例请求：“只读核验这份包装交付，按提供的确认稿和印厂要求列出证据与未检项，不修改原文件。”

不要求固定本机路径或另一个技能。实际检查AI、PDF或色彩需要使用者自己的适用软件和有效资料；本包不附检测程序。
本单明确要求优先。分层AI、转曲文字、带刀模JPG及300 DPI均是可能的订单要求，不是所有项目的默认值。

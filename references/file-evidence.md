# 最终文件证据
## 原生可编辑文件
使用本单要求的原生软件，从实际交付路径重新打开文件。不要关闭未保存的其他文档。检查只读对象属性；如需操作性试验，使用独立副本，不覆盖交付件。
记录图层和独立对象的抽查范围：文字、Logo、照片/蒙版、背景、刀模和工艺版。仅打开PDF预览、扩展名为AI或字体资源为零，不能证明可编辑、文字转曲或内容正确。
对照确认稿看各面图文，区分真实轮廓、位图文字和活文字；检查旧字旧标是否被遮盖。能选择对象不等于外观保真。

## 看稿导出
按本单指定是否带刀线、导出尺寸、分辨率与格式。不把看稿技术线设置混入生产分版。记录源文件与导出版本；同名和时间接近不能证明同版。
打开最终导出查看全图与局部，核对SKU、件数、文字、图案、裁切及批注。
若本单要求特定DPI，像素约为毫米/25.4×目标DPI，说明画板/出血/成品的范围及取整。仅改DPI标签不会增加细节，置入图像有效ppi仍须检查。
源稿改变后相关导出的一致性需重新核验。没有原生软件、色彩/条码测量工具或真实印样时写未检，不用视觉推断替代。
